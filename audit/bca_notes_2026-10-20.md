# BC Assessment: working notes (20 Oct 2026)

From the UBC Library guide "Tips for working with BC Assessment data" (J.B. screenshots, 20 Oct 2026), and what they change in tool/bca/bca_derive.py.

| Guide says | What the script does |
|---|---|
| Roll numbers are unique only within a jurisdiction; join on roll number and jurisdiction | `--jur` is now required for a run; every extract row outside that jurisdiction is skipped. The City's tax report (FOLIO = roll) is Vancouver only. New `--codes FILE --pos 2` lists the jurisdiction codes and their counts (codes only), to find Vancouver's code rather than assume it |
| Since 2022, Data Advice is six CSV tables joined on FOLIO_ID; the Residential and Non-Residential Inventory Extracts have no folio ID and join on ROLL_NUMBER + JURISDICTION | If the site descriptions come from Data Advice, pass its folio table (`--folio`) and the description table (`--desc`, `--desc-id`, `--desc-text` by column name) |
| Some folios have more than one address; use PRIMARY_FLAG = T | Not needed: the script joins through the tax report, not addresses. If addresses are ever used, keep PRIMARY_FLAG = T only |
| Sales: exclude CONVEYANCE_TYPE 5 (not market sales) | Not used. Recorded for any later use of sales |

Order of work on J.B.'s computer (the raw files never leave it):
1. Download the latest Residential and Non-Residential Inventory Extracts and the site descriptions (Data Advice) from Abacus; unzip into Downloads/BCA.
2. `--inspect` each file: column count, row count, header names. No values.
3. `--codes` on the jurisdiction column: find Vancouver's code.
4. Confirm the field positions against the user guides, then the full run. Only the derived file (heat per parcel, 2 significant figures, use group, heating group) and counts come back.
