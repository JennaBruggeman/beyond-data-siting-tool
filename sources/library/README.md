# Source library

One folder per source id (the id used in the register).

- `public/`: government, bylaw, regulator, utility and open-data documents. In git; the tool links to these at the page.
- `private/`: copyrighted documents (journals, standards, industry and company reports). Ignored by git; on J.B.'s computer only.

Each folder: `full.pdf` (or `page.html` for a web page), any older editions, and `info.json` (link, date saved, how, pages used, quote, licence, problems).
