## Shared cause (bugs 1, 2, 3)

`fitMax` assumes a smaller size never needs more room. It does not hold: the building shrinks to the size, so the roof does too.

- CLARK: 0.1–0.5 MW fail, 0.75–1.9 MW pass.
- E123: 0.1–2 MW fail, 2.5–3.8 MW pass.
- E05: 15 MW fails between 12 and 20.

New in `site.js`:
- `fitSizes()`: each slider step below `fitMax`, plus `fitMax`, checked against every hard rule.
- `fitNear(v)`: v if it passes, else the largest passing size below it.

`fitMax` itself is unchanged.
