# Code audit: hard rules, part "site" (2 Nov 2026)

Scope: tool/site.js, plant.js, scene3d.js, kit3d.js, engine.js (zoning, envelope, setup problems, what fits, plant sizing and placement, fence, 3D), index.html (flood and zone-status texts), decide.js. No tool file edited.

How blocking works today: `BD.setupProblems()` (site.js:167) gathers `m.warn` (storeys over the limit, loading spaces that do not fit, no room left) and plant that does not fit (plant.js:96–101). In the guided flow this disables Next (flow.js:118–121, 155), and `BD.fitMax()` (site.js:174) only counts sizes with no problem. Anything not in that list does not block.

"Source enough?" = whether the text already read lets the tool enforce it. "?" = not read, paywalled, or our reading.

## Most serious five

1. **Noise (1).** Sizes that break the night noise limit still count as fitting and pass the flow. The level is also measured at neighbour building centres, not at the property line or street where both by-laws measure it, so it is understated.
2. **Existing building, ground floor (14).** A retrofit in I-2, I-3 or FC-2 counts its ground floor as data hall. The tool enforces this rule for new buildings only.
3. **Fence (11, 12).** The 2.4 m fence is drawn through Vancouver's required yards, where the cap is 1.9 m (s. 10.10.3), and inside Edmonton's street setbacks. The tool never mentions either limit.
4. **Generator tanks (13).** Sub-base tanks over 2,500 L fall under NFC Part 4 and need 3 m from the property line (Table 4.3.2.1). Where the yard is 0 m the tool places them 1.5 m from it.
5. **"Largest that fits" leaves out fire access and utility transformers (17, 18).** No access route (NBC 3.2.5) and no transformer clearances (BC Hydro ES54 F, EPCOR) are reserved, so the headline size is too high on tight lots.
