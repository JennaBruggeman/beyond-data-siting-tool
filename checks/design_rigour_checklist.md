# Design rigour checklist (J.B., 1 Nov 2026: "apply this rigour to everything design related, that's what good architects do")

Every program or element the Architecture mode places goes through each lens below. Each finding is sourced, indexed in the register, checked by independent agents (at least two rounds), and labelled: rule / guidance / insurer / operator claim / maker claim / our reading / ?. Absences are recorded as "searched, not found".

| Lens | Questions |
|---|---|
| Zoning | Allowed in this zone? Conditional? Size caps, ground-floor rules, FSR share, setbacks, fence and height limits, loading and parking |
| Building code | Occupancy class; separations to every neighbour; stacking; egress (and no exit through others); accessibility; service rooms; spatial separation between masses; seismic importance; sprinklers |
| Fire code | Hazardous materials (fuel, chemicals, batteries); storage limits; fire department access |
| Program regulation | Licensing rules (pools, childcare, food, shelters); health-authority siting |
| Standards and insurers | NFPA, CSA, ASHRAE, FM and other insurers; what an insured operator is held to |
| Operator practice | What operators actually do (claims, tour observations) |
| Environment and neighbours | Noise, exhaust and air intakes, light, shadow, warm air, flood |
| Security | Secure line, layers, portals, cameras, lighting, barriers, guards, hand-over rooms, privacy limits |
| Systems and exchange | Heat, water, power shared with the data centre; meters; ownership; emergency mode |
| Envelope and structure | OUT OF SCOPE (J.B., 1 Nov 2026: the mode stays at massing). Only rules that change massing are kept, e.g. facade PV needs a sprinklered building or ≤3 storeys and a full-wall test; dome greenhouse not on a roof |
| Access and servicing | Truck routes, turning, queuing, maintenance access without crossing the secure line |
| Social fit | Who lives nearby; who uses it; who runs and owns it |
| Cost | OUT OF SCOPE for programs (J.B., 1 Nov 2026). The tool's existing cost and payback figures (heat, solar, etc.) stay as they are |

Status by program (first version): refuge, pool, greenhouse, laundry, public ground floor, roof and facade solar, secure line, hand-over room.
